# Zoologico-Colabor

Proyecto colaborativo de desarrollo web sobre un zoológico, realizado con HTML y CSS.

## Ramas del proyecto

- main: versión principal del proyecto.
- Develop: integración de los cambios de los colaboradores.
- feature/Geidy: páginas de animales y contáctenos.
- feature/Jhon-Edwin: páginas de inicio de sesión y sitios de interés.
- feature/Angelica: página de inicio y sobre nosotros.

## Objetivo

Desarrollar un sitio web que presente información sobre el zoológico, sus animales y sus diferentes secciones.
